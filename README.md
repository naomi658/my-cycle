# 나의 생리 캘린더 (PWA)

생리 시작일만 기록하면 **다음 생리 · 가임기 · 배란 예정일**을 예측해 주는 개인 주기 캘린더입니다.
아이폰 사파리에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요. 인터넷 없이도 열립니다.

- 주소: https://naomi658.github.io/my-cycle/ *(저장소 Pages를 켠 뒤)*

## 무엇이 되나요

### 오늘 — 지금 내 상태와 다음 일정
- 큰 원형 배지에 **생리 D+N일째 / 다음 생리까지 N일 / 생리 예정일이 N일 지남 / 가임기**를 한눈에.
- **생리 예정 12/10 ~ 12/14**, **가임기 11/21 ~ 11/27**처럼 날짜 구간으로 강조해서 보여 줍니다.
- 주기 요약 카드: 다음 생리 예정 · 가임기 · 배란 예정일의 실제 날짜와 D-day, 평균 주기·평균 생리 기간.
- 오늘 기록: 생리 시작/종료, 어제 시작, 출혈량(적음·보통·많음), 증상 12가지, 기분 8가지, 분비물, 메모.
  모든 입력은 그 자리에서 자동 저장됩니다.

### 캘린더 — 한 달을 색으로
- **실제 생리일**(로즈 채움) · **예정 생리일**(연한 핑크 점선) · **가임기**(민트) · **배란 예정일**(진한 민트 + 🥚).
- 오늘은 테두리로, 출혈량은 작은 점 개수로 표시합니다.
- 날짜를 누르면 그날의 상세 시트가 열려 생리 여부·출혈량·증상·기분·분비물·메모를 고칠 수 있어요.
- 아래 **이번 달 일정**에 그 달에 걸치는 `생리 (기록) 11/6 ~ 11/10`, `가임기 11/21 ~ 11/27`, `배란 예정 11월 26일`이 날짜 구간으로 나옵니다.
- 달력은 좌우로 밀어 달을 넘길 수 있고, `생리 기간으로 한 번에 기록`으로 시작일~종료일을 한 번에 넣을 수 있어요.

### 기록 — 주기 분석
- 평균 주기 · 평균 생리 기간 · 기록 구간 수.
- 최근 12개 주기의 **주기 길이 막대 그래프**(평균 점선, 정상 범위를 벗어난 주기는 연한 색).
- `최근 6회 평균`과 `전체 평균`을 함께 보여 줘서 최근 변화를 알 수 있어요.
- 생리 기록 목록(시작일~종료일, 생리 기간, 주기 길이)과 **기록 관리** 시트:
  - 여러 기간을 한 화면에서 **동시에 추가**, 기존 기간의 시작/종료일 **바로 수정**, 삭제.

### 설정 — 기본값과 백업
- 평균 주기 길이(21~45일) · 평균 생리 기간(2~10일) 기본값.
- 가임기 / 배란 예정일 표시 ON/OFF.
- **JSON 내보내기 · 불러오기**: 내 백업은 물론, **Flo 등 다른 앱의 JSON**도 읽습니다.
  - `periods`, `cycles`, `cycle_days`, `period_days`, `days`, `logs` 등 여러 구조와
    `start/end`, `start_date/end_date`, `startDate`, 배열 쌍, 날짜별 객체, 초/밀리초 타임스탬프,
    `YYYY-MM-DD` · `YYYY/MM/DD` · `M/D/YYYY` 표기를 자동으로 찾아냅니다.
  - 하루 기록의 출혈량·증상·기분·분비물·메모도 영어/한국어 이름을 알아서 매핑합니다.
  - 불러올 때 **합치기**(지금 기록 유지, 없는 날짜만 채움) 또는 **덮어쓰기**를 고를 수 있어요.
- 예시 데이터로 둘러보기, 전체 초기화.

## 예측은 이렇게 계산해요

| 항목 | 기준 |
| --- | --- |
| 생리 구간 | 연속된 생리일. 하루를 빠뜨려도 같은 생리로 보고, **이틀 이상 비면 새 주기**로 나눕니다. |
| 평균 주기 | 기록이 2구간 이상이면 실제 시작일 간격의 평균(15~60일만 사용), 그 전에는 설정 기본값. |
| 평균 생리 기간 | 기록이 2구간 이상이면 실제 구간 길이의 평균(1~14일만 사용), 그 전에는 설정 기본값. |
| 다음 생리 | 마지막 생리 시작일 + 평균 주기. 예정 구간이 이미 지나면 다음 주기로 넘깁니다. |
| 배란 예정일 | 다음 생리 예정일 − 14일 |
| 가임기 | 배란 예정일 5일 전 ~ 배란 다음 날 (7일) |
| 가임기·배란 표시 | 설정에서 각각 끌 수 있어요. |

## 기록은 어디에 저장되나요

앱에는 **실제 개인 기록이 전혀 들어 있지 않습니다.** 입력한 내용은 그 브라우저의
`localStorage`(`mycycle-v1`)에만 저장되고 서버로 전송되거나 저장소에 올라가지 않습니다.
브라우저 데이터를 지우면 함께 사라지니, 가끔 **설정 → 내보내기**로 백업해 주세요.
내보낸 JSON에는 개인 기록이 들어 있으니 공개된 곳에 올리지 마세요.

## 아이폰에 설치

1. 사파리에서 주소를 엽니다.
2. 아래 **공유** 버튼 → **홈 화면에 추가**.
3. 홈 화면의 아이콘으로 실행하면 주소창 없이 앱처럼 열립니다. (한 번 열면 오프라인에서도 동작)

| --- | --- |
